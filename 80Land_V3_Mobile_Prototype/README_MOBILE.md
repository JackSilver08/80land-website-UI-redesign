# 80Land Mobile Prototype

Bản mobile độc lập, chạy tĩnh bằng một file HTML.

Mục tiêu:
- Giữ visual direction của Stitch V3.
- Mobile-first, 390px reference.
- Search-first, listing rõ ràng, bottom navigation.
- Có đầy đủ các flow Renter: Home, Search, Map, Detail, Saved, Messages, Notifications, Profile, 80Land Assistant.
- Có mobile view cho Landlord, Admin và Province Hub.
- Không cần backend, Node.js hay database.

Mở `mobile.html` bằng Chrome/Edge hoặc bật Device Toolbar để xem responsive.
