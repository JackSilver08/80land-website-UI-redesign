# Static Architecture

The project remains static and backend-free for client review.

- HTML shell: index.html
- Bootstrap 5: layout, responsive utilities, tables, buttons, list groups
- Custom CSS: brand, header, hero, property cards, map, detail components
- ES Modules: router.js, data.js, app.js
- Data: js/data.js
- Routing: History API + route rendering
- Prototype persistence: localStorage for selected saved-listing state

The Stitch single-file prototypes remain available as visual references under the existing folders, but the refactor target uses the root structure.
