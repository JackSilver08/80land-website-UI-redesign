## UX
1. Search-first marketplace UX.
2. Preserve functionality while reducing cognitive load.
3. Header secondary actions are icon-first with desktop tooltips.
4. Listing cards are dense but scannable.
5. Mobile core actions use bottom navigation.
6. Bootstrap 5 handles grid/responsive primitives; custom CSS owns 80Land visual language.
7. Do not copy Chợ Tốt branding or visual assets.
