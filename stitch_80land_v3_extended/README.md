## Chạy
Mở `index.html` hoặc `code.html` trực tiếp bằng Chrome/Edge. Không cần Node.js, database hoặc backend.

## Demo quan trọng
- Bấm một property card -> mở trang Chi tiết phòng.
- Bấm Lưu tin -> cập nhật Tin đã lưu bằng localStorage.
- Vào Tin nhắn -> chọn hội thoại và gửi tin nhắn demo.
- Vào Thông báo -> đánh dấu đã đọc.
- Tài khoản -> xem hồ sơ, số liệu và cài đặt nhanh.
